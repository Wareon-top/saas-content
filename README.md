# Nexus TikTok Control Center

Первый интерфейсный MVP для управления портфелем TikTok-каналов.

## Что уже есть

- премиальный dashboard в тёмной теме;
- разделы: обзор, каналы, статистика, публикации, монетизация и активность;
- адаптивная вёрстка;
- реалистичные mock-данные и интерактивная навигация;
- форма подготовки публикации без подключения аккаунтов и API-ключей.

```bash
npm install
npm run dev
```

## Текущие границы MVP

Интерфейс намеренно не хранит пароли TikTok, cookies браузера, прокси-данные или токены. Следующий этап — подключение OAuth TikTok, синхронизации каналов и серверной модели данных.
